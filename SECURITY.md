# Security Policy

## Supported Version

This repository is maintained as a portfolio/educational project. Security fixes should target `main`.

## Reporting

Please open a private security advisory if available, or contact the repository owner directly before filing a public issue for exploitable vulnerabilities.

## Scope

This app is not a clinical or psychological assessment product. It is a small full-stack demo with cookie-based auth, CSRF protection, SQLite-backed sessions, rate limiting, admin audit logs, and a demo admin password model.
